# 答题锁 TV（QuizLock）使用说明

> 作者：高飞　|　一个纯离线的安卓电视"答题解锁看电视"App，题目由你用 AI 生成后放入，App 不内置任何 AI、不需 API Key、不花钱。

## 功能（已按你的要求实现）
- 电视**开机后先弹一道题**，答对才能看
- 之后**每满 10 分钟**自动弹一道全屏题（间隔可在 App 里调，1~1440 分钟）
- **全屏锁屏**覆盖电视画面，屏蔽返回键，无法绕过
- 题型：**单选 + 判断**混合，每次只弹一题
- **答对 → 解锁继续看**；**答错 → 追加一道新题，直到答对**
- **防乱点（修复“孩子闭眼狂点A蒙对”漏洞）**：默认需**连续答对 3 题**才解锁，答错计数清零重来；且**单选题选项每次随机打乱**，靠蒙通过率降到约 1.6%。连对数可在主页调 1~10（孩子越小/越难管就调越大）。
- 题目来源：**给你留了"开口"**，两种方式放题库（见下）

## 题库入口（核心：你说的"留个入口我把题库放进去"）
装好后打开 App，主页就是"题库入口"，两种放入方式：

**入口A｜粘贴导入（最简单）**
1. 用 WorkBuddy / 任何 AI 生成题库（提示词模板见下）
2. 把输出的 JSON 复制，粘进 App 的"粘贴导入"框 → 点"保存并导入"
3. 立即生效，共 N 题显示在顶部

**入口B｜链接自动同步（体现"自动更新"）**
1. 把题库存成一个 `.json` 文件，放到**公开可读**的地址（网盘分享直链、或自己的小服务器，需以 http/https 直接返回 JSON 文本）
2. 在 App 填这个地址 →"保存地址"→"立即同步"
3. 以后你改了那个文件，电视点"立即同步"就自动更新，**无需重装 App**

## 喂 AI 的提示词模板（直接复制，只改知识点）
```
你是高一老师。请按知识点"【填：如 函数单调性】"出 12 道题，8 道单选、4 道判断，难度贴合高一课本进度。
只输出一个 JSON、不要任何多余文字，严格用这个结构：
{"questions":[
 {"type":"single","stem":"题干","options":["A项","B项","C项","D项"],"answer":正确项下标(0~3),"analysis":"解析"},
 {"type":"judge","stem":"题干","answer":true或false,"analysis":"解析"}
]}
单选 answer 是正确选项下标(从0数)；判断题 answer 是 true/false。
```
> `sample/题库示例-灵犀.json` 是一个可直接粘进去试用的例子（高一数学 6 题）。

## 编译成 APK（你选了"云端编译，本机不装环境"）
需要**一个 GitHub 账号**。两种方式：
- **你给仓库授权**：我建私有仓库、推送这套代码，GitHub Actions 自动编译，下载 `QuizLockTV-debug.apk`
- **你自己传**：把 `QuizLockTV` 整个文件夹推到一个 GitHub 仓库，Actions 会按 `.github/workflows/build.yml` 自动出 APK

## 安装到小米电视
1. 电视：设置 → 关于 → 连续点"产品型号/版本号"7 次 → 开启开发者模式 → 打开 USB/网络调试
2. 电脑装个 adb，`adb connect 电视IP:5555`（先点"允许调试"）→ `adb install QuizLockTV-debug.apk`
3. 装好后在电视打开 App，导入题库；首次进电视"设置-应用-答题锁TV-权限"，授予**悬浮窗 + 自启动 + 无电池优化**，弹窗才不被清理

## 说明与注意
- App 是 debug 版可直接装；正式长期用建议后续配签名
- 极老/特殊 ROM 若前台弹锁屏受限，可在电视设置里把本 App 设为"允许显示在其他应用上层"
- 想彻底防孩子绕过（断电重启等），可叠加 cleanyourtv 去掉电视入口干扰
